# 전체 스테이지 제작 묶음

상태: REVIEW — 전체5지역 후보 구현·기술 검증 완료, Director 통합 실기 검증 대기 / 2026-09-08

Director가 Stage 1·2 실기 검증 완료를 알리고, 몬스터 공격 이펙트 보강 및 전체 스테이지 작업 완료를 요청했다. 이 요청을 Stage 3·4·5 생산 착수 승인으로 기록한다. 기존 main 통합이나 Commit 승인은 별개다. 실측 플레이 시간 및 기기 정보는 제공되지 않았으므로 임의 기록하지 않는다.

## 이번 결과물

- Stage 1 외곽, Stage 2 야수숲의 검증된 기본 동작 유지.
- Stage 3 성벽: 고저차와 원거리 공격 사이에서 안전한 접근 위치 선택.
- Stage 4 돌성소: 예고된 지면 강타를 점프/거리 이탈로 피하고 회복 중 반격.
- Stage 5 성채: 기존 위협의 종합 전투와 마지막 Goal, 캠페인 결말·재도전.
- 인간형 근접/사수/야수/골렘이 구별되는 예고·공격·회복 이펙트. 공격 판정과 시각 타이밍 동기화, 불필요한 화면 가림 제한.
- 특성 1슬롯·HP3·사망 우선·각 Stage 체크포인트·세션 진행 유지.

## 제외 및 검증 경계

영구 저장, 경험치/파밍, 추가 특성 묶음, 새 회피 무적, 스토어 배포, Commit/Merge/Push는 하지 않는다. 기존 20~30분은 5지역 캠페인의 목표이며 자동 fixture 시간으로 달성을 주장하지 않는다. 자동 회귀·실행·시각 검증을 완료한 뒤 변경된 전체 게임에 대해 Director 검증을 요청한다.

## 실제 제작값

| 지역 | 구간별 적 수 | 구별되는 플레이 |
|---|---|---|
| 1 성문 외곽 | 1 / 1 / 2 / 3 | 근접·원거리 기초, 혼합 위협 |
| 2 야수숲 | 1 / 2 / 2 / 3 | 방향 고정 돌진을 피하고 반격 |
| 3 무너진 성벽 | 1 / 2 / 2 / 3 | 높이80px 사수 발판과 상부 길, 공중 접근·공격 |
| 4 돌의 성소 | 1 / 2 / 2 / 2 | 골렘 중앙 지상 강타와 회복 빈틈 |
| 5 침묵의 성채 | 2 / 2 / 2 / 3 | 근접·사수·야수·골렘 종합, 마지막 Goal과 결말 |

공통 네 구간의 완료와 생존한 Goal 도착이 각 Stage 성공 조건이다. 중간 체크포인트 이후 실패는 해당 지역 E1/E2 완료를 유지하고 E3/E4를 새로 생성한다. 완료된 이전 지역과 선택 특성은 같은 세션에서 유지한다. 새 지역 시작은 HP3이며 최종 재도전은 Stage1·기본 검술로 초기화한다.

골렘은 HP3, 중앙220×30 지상 판정, 예고0.85초·활성0.18초·회복1.35초를 사용한다. 기존 Stage1의 골렘 외형 근접 적과 구별되는 Stage4/5 전용 행동이다. Stage5 마지막은 기존 위협의 종합 전투이며 별도 다단계 보스를 추가한 것은 아니다.

성벽 사수의 초기100px 발판안은 기본 점프 높이와 맞지 않아80px로 조정했다. 필수 구간은 연속 바닥이며 추가 발판은 점프 실패 시 바닥으로 복귀한다. 체력 증량·강제대기로 분량을 늘리지 않았다.
