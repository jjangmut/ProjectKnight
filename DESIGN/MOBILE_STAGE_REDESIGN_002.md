# 모바일·복층 스테이지 개선 묶음

상태: REVIEW — 기술 QA22종 PASS, Director 실기 검토 대기 / 2026-09-09 / 결정: DEC-006

## 담당과 범위

Studio Manager 조정, Client 담당 모바일 입력·HUD, Level 담당 경로·전투, Art 담당 지역 지형, 독립 Review/QA 검증. 기존 미커밋 후보를 보존하고 그 위에 적용한다.

## 제작 계약

- 이동·공격·점프·검막기 입력 유지. 공격은 홀드 반복, 점프는 0.14초 버퍼와 0.12초 유예. 막기는 홀드 유지·지상·방향 고정, 일반 정면 공격만 차단.
- 각 지역 기존 6600px 길이 안에 1480~2600, 4380~5740 두 상층 분기와 하층 복귀. 단차 최대60px, 넓은 발판, 아래 연속 바닥. 실패 시 낙사시키지 않는다.
- 필수 전투 E1~E4는 3/3/4/4명(총14), 한 웨이브 최대2. 선택 전투 두 곳 각2명으로 지역당 최대18명, 전체90명. 필수 경로만 선택하면 전체70명이다.
- 숲은 돌진, 성벽은 원거리, 성소는 강타, 성채는 혼합 위협. 상층 선택 전투는 건너뛰어도 Goal 진행에 영향이 없다.
- 선택 전투 완료 HP+1(cap3), 최초 완료 소비. 체크포인트에는 완료를 유지한다. 기본 필수 E1/E2 유지·E3/E4 재생성·HP3·탄 제거를 유지한다.
- 지역별 석축/뿌리흙/성벽/성소/성채 텍스처와 착지면 테두리, 장식 지지 구조를 적용한다. 장식 지지대는 충돌이 없다.

## 완료 확인

- 실제 입력으로 다섯 지역 상층 진입·합류·Goal 이동, 실패 점프의 하층 복귀.
- 선택 전투 미방문 성공, 필수 전투 미완료 성공 금지, 동시 사망 우선.
- 공격 홀드·점프 유예/버퍼 단일 사용·막기·터치 동시 입력·포커스 상실 해제.
- 선택 보상 저체력/만피/중복/체크포인트 재개/새 Stage 초기화.
- 기존 전투·특성·체크포인트·캠페인 회귀와 GPU 화면 검토.

## 분량과 한계

적 수 39→90은 배치량이지 성공시간의 증거가 아니다. 맵 길이 자체를 늘리지 않고 기존 빈 공간에 복층·선택 전투와 추가 전투량을 넣었다. 기존 20~30분은 여전히 실측 필요 목표다. 본 묶음은 분량 개선 후보이며, 첫 성공 시간·오입력 사망·전투 공백·경로 선택의 의미를 사람 플레이로 판정한다.
