# 결정(Decision)

결정 ID: DEC-006
제목: 모바일 조작 부담 완화와 복층·선택 경로 확장
상태: ACTIVE
결정일: 2026-09-09
결정자: 스튜디오 디렉터 — 개선안대로 작업 진행 승인

## 결정 내용

- 공격 홀드 반복, 점프 입력 버퍼·발판 이탈 유예를 추가한다. 막기는 지상·방향 고정·정면 일반 공격 방어를 유지하며 홀드 시간 제한과 반복 재입력 부담을 없앤다.
- 초기 비교 값: 점프 버퍼 0.14초, 유예 0.12초, 막기 종료 회복 0.12초·재사용 0.2초(동시 시작). 기존 DEC-005의 0.8초 제한을 대체한다. HP3·강공격/후방 취약·패링 없음은 유지한다.
- 모든 지역에 상층 분기와 하층 합류를 만들고, 필수 전투와 선택 전투를 분리한다. 필수 네 전투 완료·생존 Goal 도착만 Stage 성공 조건이다.
- 적 전체 수는 늘리되 필수 전투는 1~2마리씩 순차 투입한다. 적 체력이나 강제 대기로 시간을 늘리지 않는다.
- 지역 배경에 맞는 바닥·발판 재질을 적용한다. 모바일 터치 입력과 안내를 함께 개선한다.

## 전문 기획 검토

선택 전투 전체 완료 시 HP +1(최대3)을 한 번 지급한다. 만피여도 지급 기회를 소모한다. 체크포인트 복귀에는 선택 전투 완료 자체를 유지하여 반복 회복을 막는다. Stage 처음부터 새 시작 시 초기화한다. 영구 저장이나 별도 보상 보관 기능은 만들지 않는다.

## 검증 경계

시간과 편의성은 실측 플레이 검토 대상으로 남긴다. 자동 기술 PASS를 모바일 실기·재미·20~30분 달성으로 해석하지 않는다. 후보 Worktree 작업 승인이고 Commit/Merge/배포 승인은 아니다.
