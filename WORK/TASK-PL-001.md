## 스튜디오 디렉터 최초 지시

> Project Knight는 마계촌과 같은 고전 2D 횡스크롤 액션 게임에서 영감을 받은 모바일 게임으로 한다.
>
> 원작을 복제하지 않고 오리지널 IP로 제작한다.
>
> 첫 목표는 5~10분 분량의 플레이 가능한 프로토타입이다.
>
> 스튜디오 매니저는 기획 리드, 아트 리드, 클라이언트 리드, 사업 / 서비스 리드의 의견을 받아 첫 프로토타입의 방향과 범위를 제안하라.
>
> 서버 리드는 현재 단계에서 서버가 실제로 필요한지부터 판단하라.
>
> 이번 단계에서는 구현을 시작하지 말고, 프로젝트 방향과 프로토타입 범위만 제안하라.

## 작업 내용

- 고전 2D 횡스크롤 액션에서 영감을 받은 모바일 게임의 프로토타입 방향과 범위를 제안한다.
- 원작을 복제하지 않고 오리지널 IP를 전제로 한다.
- 관련 리드(Lead)의 전문 의견을 수집하고 비교한다.
- 서버 리드는 현재 단계에서 서버가 실제로 필요한지부터 판단한다.
- 이번 단계에서는 구현을 시작하지 않는다.

## 작업 범위

- 핵심 플레이 루프
- 모바일 조작 방식 후보
- 5~10분 분량의 프로토타입 범위
- 포함 기능과 제외 기능
- 개발 난이도와 주요 위험요소
- 아트 제작 방향 초안
- 서버 필요 여부
- 시장과 타깃 관점의 초기 의견

## 제외 범위

- 게임 구현
- 세부 팀별 작업 생성
- 정식 게임명, 세계관, 캐릭터와 스테이지 확정
- BM, 최종 아트 스타일, 게임 엔진과 서버 구조 확정
