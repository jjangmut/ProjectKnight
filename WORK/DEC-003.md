## 결정 내용

Project Knight의 기준 엔진 버전은 **Godot 4.7.2 stable Standard 빌드**로 고정한다. 게임 로직은 GDScript를 사용하며 C#/.NET 빌드는 사용하지 않는다.

2D 모바일 프로토타입과 폭넓은 모바일 호환성을 우선하여 Compatibility 렌더러를 사용한다.

버전은 자동으로 업데이트하지 않는다. 업데이트가 필요하면 영향과 검증 결과를 기록한 별도 결정(Decision)으로 처리한다.

## 결정 이유

- 2026-09-05 기준 Godot 4.x의 최신 안정 유지보수 릴리스다.
- Godot 4.8은 개발 버전이므로 프로토타입 기준 버전으로 사용하지 않는다.
- 신규 프로젝트이므로 Godot 3.x가 아닌 Godot 4.x를 사용한다.
- GDScript 기반으로 AI Agent가 빠르게 작성·수정하기 쉬운 구조를 유지한다.
- Project Knight는 2D 모바일 프로젝트이므로 Standard 빌드를 사용한다.
- Compatibility 렌더러는 2D와 폭넓은 모바일 하드웨어 지원에 적합하다.

## 검토한 대안

### 대안 A — Godot 4.7.2 stable Standard

설명: 최신 4.x 안정 유지보수 릴리스와 GDScript를 사용한다.

장점:

- 안정 릴리스 기준으로 신규 프로젝트 시작 가능
- GDScript와 Godot 기본 구조를 직접 사용
- C#/.NET 의존성 없음

단점:

- 버전 고정 후 새로운 기능과 수정은 자동 반영되지 않음

### 대안 B — Godot 4.8 개발 빌드

설명: 개발 중인 다음 기능 릴리스를 사용한다.

장점:

- 최신 개발 기능을 먼저 사용할 수 있음

단점:

- 개발 버전으로 프로토타입 기준선의 안정성이 낮음

### 대안 C — Godot 4.7.2 .NET

설명: 동일 엔진 버전에서 C# 지원 빌드를 사용한다.

장점:

- C#과 정적 타입 개발 경험을 활용 가능

단점:

- 이번 프로젝트의 GDScript 우선 결정과 맞지 않고 추가 .NET 의존성이 생김
