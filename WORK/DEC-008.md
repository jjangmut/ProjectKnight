# 결정(Decision)

결정 ID: DEC-008
제목: 프로토타입 종료 및 버티컬 슬라이스 프로덕션 전환 — 기획 데이터 연속 생산과 그래픽 품질 혁신
상태: ACTIVE
결정일: 2026-09-09
결정자: 스튜디오 디렉터
관련 결정: DEC-005, DEC-006, DEC-007의 기술 기반을 바탕으로 상용 퀄리티 진입

## 결정 내용

Director의 명시적 승인에 따라 단순 플레이 체감 검토 단계를 공식 종료하고, 상용 게임 수준의 깊이 있는 게임성과 시각 품질을 달성하기 위한 **버티컬 슬라이스(Vertical Slice) 1차 프로덕션**에 즉각 착수한다.

1. **기획 부문 (Planning)**:
   - 전투 메커니즘 심화: 정면 막기 성공 직후의 카운터 어택(Counter Advantage), 공중 하향 찍기(Down Thrust), 3단 공격 콤보를 설계한다.
   - 데이터 드리븐(Data-Driven) 전환: 하드코딩된 스테이지/적 배치를 전면 중단하고, `monsters.json`, `stage_01.json` 등 독립 데이터 테이블 시트를 지속 생산한다.
   - 보스 및 특수 기믹 기획: 지역별 고유 중간보스/보스 페이즈 및 환경 트랩/기믹 명세를 수립한다.

2. **아트 부문 (Art)**:
   - 캐릭터/몬스터 풀 스프라이트화: 기사 플레이어 6대 액션(대기/달리기/3단공격/방어/점프/피격) 풀 프레임 스프라이트 규격 확정 및 제작.
   - 공격 전조(Telegraph) 표준화: 몬스터 모션 전조, 안광 이펙트, 바닥 먼지 등 시각적 3대 전조 규칙 적용.
   - 배경 4계층 패럴랙스(Parallax) 및 타일셋(TileSet) 구축: 단순 반복 텍스처를 걷어내고 유기적 오토타일 및 다층 원경/중경/전경 환경을 연출한다.

3. **클라이언트 및 시스템 (Client / System)**:
   - Data-Driven StageLoader: 기획 JSON 데이터를 파싱하여 인카운터와 지형을 동적 배치하는 로더 아키텍처를 구현한다.
   - 오디오 및 이펙트 버스: 타격음, 방어 금속음, 환경음, BGM을 통합 관리하는 `AudioManager`를 정식 연동한다.
   - 로컬 영구 세이브: 세션 메모리 상태를 안전한 로컬 저장 파일(`user://save_data.json`)로 보존하는 저장 시스템을 구축한다.

4. **품질 검증 (Review / QA)**:
   - 데이터 스키마 유효성 검사기(Schema Validator)를 마련하여 데이터 무결성을 검증하고, 신규 전투 기믹 및 보스 패턴의 물리/회귀 테스트를 자동화한다.

## 이유와 효과

프로토타입 기능 검증이 완료된 시점에서 불필요한 관찰 대기를 생략하고, 본격적인 상용 프로덕션 파이프라인(기획 데이터 생산 → 아트 에셋화 → 클라이언트 구현 → QA 검증)을 가동하여 게임의 본질적인 재미와 완성도를 비약적으로 향상시킨다.
