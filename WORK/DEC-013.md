# [DEC-013] 모바일 가상 컨트롤러(Virtual Controller) 및 Android APK 빌드 파이프라인 수립

- 결정일: 2026-09-10
- 결정자: Project Manager & Client Lead
- 상태: DECIDED & IMPLEMENTED

## 1. 배경 및 문제
모바일(Android) 환경 출시를 위해 모바일 화면비에 최적화된 가상 터치 컨트롤러(D-Pad 및 액션 버튼 클러스터)와 조작 기능, 그리고 APK 빌드 환경 구축이 필요함.

## 2. 핵심 결정 사항
1. **모바일 가상 컨트롤러 HUD (MobileControls)**:
   - 좌측 D-Pad (◀, ▶, ▼) 및 우측 4개 액션 클러스터 (⚔ 공격, 🦘 점프, 💨 대시, 🛡 방패) 배치.
   - 멀티터치(Multi-touch) 독립 인덱스 추적으로 양손 동시 조작 완벽 지원.
   - `Input.action_press` / `release` 에뮬레이션으로 기존 플레이어 조작 체계 100% 호환.
2. **모바일 환경 최적화**:
   - 가로 센서 모드 (`window/handheld/orientation = 5`) 적용.
   - 마우스 터치 에뮬레이션(`pointing/emulate_touch_from_mouse = true`) 활성화로 PC 에뮬레이터 및 에디터 테스트 지원.
3. **Android APK 빌드 환경**:
   - Android SDK (API 34/35, build-tools 35.0.0), Java JDK, Debug Keystore 연동.
   - `export_presets.cfg`에 Android 프리셋(`com.junypapa.projectknight`, arm64-v8a/armeabi-v7a) 등록.
