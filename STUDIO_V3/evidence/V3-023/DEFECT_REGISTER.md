## 2. Explicit Art & Scope Limitations (`DIRECTIONAL_ART_MISSING`)

| ID | Category | Status | Description & Compensating Measure |
| :--- | :--- | :--- | :--- |
| **V3-023-L1** | `DIRECTIONAL_ART_MISSING` | **DOCUMENTED LIMITATION** | The current 2D hero sprite sheet (`Character_side_attack.png`, `Character_side_idle.png`, `Character_side_walk.png`) contains side-view (`left`/`right` via `flip_h`) character drawings only and does not include dedicated 2D front-facing (`Z+`) or back-facing (`Z-`) torso/swing sprite sheets. To make 8-way (`X/Z`) attack direction unmistakable in gameplay without faking missing 2D art, V3-023 adds: (1) a 3D cyan ground locator ring (`HeroLocatorRing3D`) with a rotating golden aim arrow (`HeroAimArrow3D`), (2) full 8-way rotation + horizontal X-axis tilt (`-76°`) on the 3D slash crescent (`slash_visual_3d`) so Z-axis attacks sweep across the floor toward `Z-` or `Z+`, and (3) exact 8-way alignment of `attack_area_3d` and knockback vectors. |

Live human controller/keyboard playtest feel remains pending human operator verification (`GAMEPLAY_GATE_PENDING`). |
