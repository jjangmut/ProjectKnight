## 승인 전에 수정할 사항

**1. 실제 원클릭 실행 미확인 (P0).** `SingleEntryRunner`의 단계 함수는 이미 생성된 session ID를 받아 결과를 수집합니다. `subagent_bridge.py`의 `dispatch` 역시 바인딩된 기존 세션을 조회합니다. 새로 생성한 `cli run-loop --adapter bridge`는 사전 세션 바인딩이 없으므로 새 서브에이전트를 직접 실행하지 않습니다. 한 번의 실행 진입점에서 실제 호출과 재작업까지 연결된 증거가 필요합니다.

**2. 세션과 작업의 연결 검증 부족 (P0).** 브리지는 서브에이전트 역할을 확인하지만 세션이 현재 작업 ID, 실행 ID, 검수 대상 커밋에서 시작됐는지 확인하지 않습니다. 공급자 호출 시점의 작업 연결 정보와 최종 결과의 일치 여부를 검증해야 합니다.

**3. 테스트 모드의 승인 경계 미완성 (P0).** 승인 정책 함수의 `allow_mock` 기본값이 True이고 예외 검사에 사용한 모의 공급자 이름이 실제 `MOCK_SIMULATED`와 다릅니다. 테스트 승인과 실제 개발 마일스톤 승인을 완전히 분리해야 합니다.

**4. Git 증거 버전 불일치 위험 (P1).** `submit_work`는 실행자 작업물의 SHA가 아니라 현재 저장소 HEAD를 선택합니다. `queue.json`의 V3-002-R2 검수 SHA는 픽스처 커밋이며 최신 구현 커밋과 다릅니다. 작업자 커밋과 실제 제출 파일의 일치 여부를 확인해야 합니다.

**5. 완료 후 잠금 기록 잔류 (P1).** 승인된 픽스처에 이전 실행의 `lease_owner`가 그대로 기록되어 있습니다. 승인과 잠금 해제를 하나의 상태 변경으로 처리하고 재검증해야 합니다.

**6. 테스트 재현 자료 부족 (P1).** 보고서에서 언급한 Python 원본 로그와 Godot 21개 테스트의 재실행 자료가 검수한 GitHub 트리에 모두 포함되어 있지 않습니다. 테스트 파일, 명령, 원본 결과를 함께 제출해야 합니다.
