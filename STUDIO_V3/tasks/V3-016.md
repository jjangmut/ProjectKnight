## Reason for task: performance proof is NOT reliable yet

Independent GitHub inspection of `STUDIO_V3/evidence/V3-015/BASELINE_PERFORMANCE.json` and `AFTER_PERFORMANCE.json` found:
- baseline: **19 samples**, avg draw calls **231.89**, reported avg FPS **11.95**, avg frame time **25.36 ms**.
- after: **19 samples**, avg draw calls **233.79**, reported avg FPS **1.00**, avg frame time **53.23 ms**.
- Draw calls rose only 0.8%, but measured frame time rose about 110% and FPS readings are inconsistent with the frame-time numbers. This is **not** a validated 60 FPS result. Existing report dismisses difference as headless variance without a controlled matched-run experiment. Treat these metrics as invalid for claims of mobile playability until reproduced and explained; don't simply label an unexplained regression PASS.
