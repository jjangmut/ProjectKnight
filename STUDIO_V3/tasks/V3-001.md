# V3-001 — Clean Baseline Audit and Gameplay Plane Decision

Status: READY
Owner: PK_ClientLead
Reviewers: PK_QALead, PK_GameDirector

## Goal
Create a **new**, independently verifiable baseline for ProjectKnight's existing 3D environment + Sprite3D game, without using previous VS-001 scores or reports.

## Steps
1. Verify checkout branch and source revision. Confirm previous process files are retired and the running game is unaffected.
2. Inspect SideQVStage1, SideQVPlayer, SideQVCamera, TitleScreen and campaign startup.
3. Record actual X/Y/Z movement behavior, input mapping, camera projection, depth occlusion, collision and animation.
4. Run Stage 1 in an actual graphical window; capture entry, walk, depth input, attack, boss telegraph, boss fight.
5. Run input-driven Stage 1 combat and boss progression; keep unmodified game states. Record script errors and reproduction cases.
6. Measure windowed PC performance with machine, display mode, VSync and raw per-frame data. Do not use the retired perf report.
7. Prepare DESIGN_DECISION.md comparing fixed X/Y side-scrolling vs X/Z belt-scrolling, with impacts to controller/camera/enemy AI.
8. QA reviewer verifies commands, captures and results; Director chooses intended motion plane. Missing proof -> FIX_REQUIRED.
