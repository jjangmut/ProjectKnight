## 2. Checkpoint A — fix REAL Stage3 Option C plane and projectile mechanics (P0)

Source-observed defects:
- side_qv_stage_3.gd RangedMinion spawns at Z=-1.8,+1.8, inconsistent with gameplay Z=0.
- side_qv_ranged_minion.gd uses full 3D diff.length, diff.normalized and velocity.z in pursuit/retreat/stun.
- side_qv_crossbow_commander.gd uses velocity.z when retreating, pursuing and during stunned paths; BACKSTEP_SHOT directly assigns random velocity.z=randf_range(-1.5,1.5).
- FAN_VOLLEY rotates horizontal bolt vector around Vector3.UP by +/-22 degrees, causing Z-depth separation rather than spread in gameplay X/Y plane.
- RAPID_BARRAGE adds random aim_dir.z, causing bolts to leave gameplay plane.
- CALTROP_TRAP scatters 3 of 4 traps off the lane at Z ±1.4/-0.6, while player Z=0. Trap slow still handles move_speed_z, no longer gameplay input.
- side_qv_crossbow_bolt.gd advances global_position by direction*speed*delta and relies on Area3D.body_entered; high-speed tunneling risk needs real collision verification.

Required changes:
A1. Minions spawn at Z0 and stay Z0/vz0 while aiming, moving, stunned and dying; use horizontal X spacing while preserving Y/gravity.
A2. Commander stays at Z0/vz0 in all patterns, groggy, death, and backstep, preserving X/Y airborne leap.
A3. All damaging crossbow bolt paths stay on Z=0. For fan spread rotate the 2D aim vector in X/Y plane (correct axis e.g. Vector3.FORWARD), rather than Vector3.UP. Five-shot barrage can vary vertical aim but not Z. Make telegraph visually match damaging projectile trajectory.
A4. Validate high-speed bolts hitting real player/world, without tunneling, repeated hit, shooter self-hit, or lingering projectiles after death/scene switch. Add narrow swept ray/shape collision if runtime confirms tunneling, with correct layer mask and single-hit gate. Actual hit/miss/guard/dash/parry outcomes matter.
A5. Put distinct, readable trap positions along gameplay X line at Z0, ensure single trigger and correct 2s slow expiry; avoid stacked slow effects prematurely restoring wrong speed, and clean up on stage transition.
A6. Use presence-aware actor+bolt telemetry; absent=NA. Verify X/Y trajectory with before/after projectile positions and Z/vz for multiple shots/states, not just object spawn.
Checkpoint A must produce actual Stage3 game-source changes, run targeted Godot tests and commit A before decorative art tasks. If P0 fails, fix gameplay first.
