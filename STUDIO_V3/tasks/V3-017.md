## Why now
V3-010–016 delivered five-stage desktop vertical slice, virtual touch controls, combat sound/FX, defeat/retry, stage intermissions, and desktop frame-pacing evidence. However **no Android APK or physical-device gameplay has been verified**. The actual V3-016 benchmark samples 300 frames x 3 runs with VSync enabled on RTX 5060; it measures a **60 Hz capped desktop window**, not mobile 60 FPS or GPU headroom. In benchmark code `target_60fps_satisfied` is calculated from mean frame time only and allows 17.50ms; 1%-low timings in the report reach ~18ms or more. Some `TIME_PROCESS` readings are larger than VSync frame intervals and deserve interpretation rather than being dismissed. Avoid treating V3-016 approval as certified mobile performance.

Package should launch `TitleScreen.tscn`.
3.
